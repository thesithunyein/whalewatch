## Demo Preparation Checklist

### Before Recording

1. **Get Birdeye API Key**
   - Sign up at https://docs.birdeye.so/
   - Generate API key
   - Add to Vercel environment variables

2. **Deploy to Vercel**
   ```bash
   vercel login
   vercel
   ```

3. **Test the App**
   - Verify whale feed is working
   - Check token screener
   - Test alert system (if implemented)
   - Ensure all pages load correctly

4. **Prepare Test Data**
   - Have some whale transactions ready (use mock data if API fails)
   - Prepare whale wallet addresses
   - Have tokens with high volume ready

### During Recording

1. **Screen Recording Tool**
   - Use OBS Studio or Loom
   - Record at 1080p or higher
   - Include system audio for voiceover

2. **Voiceover Tips**
   - Speak clearly and confidently
   - Keep it under 3 minutes
   - Match visuals to narration
   - Practice timing before final recording

3. **Visual Quality**
   - Use high-contrast theme (dark mode)
   - Ensure text is readable
   - Smooth transitions between scenes
   - Highlight important elements

### After Recording

1. **Edit the Video**
   - Trim dead time
   - Add text overlays
   - Include background music (optional)
   - Add transitions

2. **Export Settings**
   - MP4 format
   - 1080p resolution
   - Under 100MB for easy upload
   - Good audio quality

3. **Upload to YouTube**
   - Title: "WhaleWatch - Real-time Solana Whale Tracking"
   - Description: Include project link and features
   - Make public or unlisted (for judges)

---

## Alternative: Live Demo

If video recording isn't possible, prepare a live demo:

1. **Prepare the Environment**
   - Have the app deployed and running
   - Test all features beforehand
   - Have backup data (mock data) if API fails

2. **Demo Flow**
   - Start with problem statement (1 min)
   - Show live whale feed (1 min)
   - Demonstrate smart money tracking (30 sec)
   - Show alert system (30 sec)
   - Token screener (30 sec)
   - Q&A (remaining time)

3. **Live Demo Tips**
   - Have a stable internet connection
   - Use a reliable browser (Chrome)
   - Clear cache before demo
   - Have backup screenshots ready
   - Practice the flow multiple times
